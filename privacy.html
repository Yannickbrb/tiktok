Privacy Policy — Media Agency

Last updated: May 4, 2025

This Privacy Policy describes how Media Agency handles information in connection with its use of the TikTok API and other social media platform APIs.

1. About Media Agency

Media Agency is a private automated content publishing application. It is not a public application and is used exclusively by its owner.

2. Information We Access

Media Agency accesses the following information through the TikTok API, solely to enable its core functionality:

  • user.info.basic : Display name and profile information, used only to confirm the correct account is connected.
  • video.upload : Permission to upload video files to the authenticated TikTok account.
  • video.publish : Permission to publish uploaded videos on the authenticated TikTok account.

3. How We Use Information

Media Agency uses accessed information solely to publish video content on behalf of the authenticated account owner. We do not use this information for any other purpose.

4. Data Storage

Media Agency does not store any TikTok user data on external servers. All data processed by Media Agency remains on the owner's local machine or private server. No data is transmitted to third parties.

5. Data Sharing

Media Agency does not sell, trade, rent, or share any user data with third parties under any circumstances.

6. Third-Party APIs

Media Agency integrates with the following third-party APIs :

  • TikTok Content Posting API (subject to TikTok's Privacy Policy)
  • YouTube Data API (subject to Google's Privacy Policy)
  • Instagram Graph API (subject to Meta's Privacy Policy)

7. Security

All API credentials and tokens used by Media Agency are stored locally and are never transmitted to external services other than the respective platform APIs.

8. Children's Privacy

Media Agency is not intended for use by individuals under the age of 13. We do not knowingly collect information from children.

9. Changes to This Policy

This Privacy Policy may be updated periodically. The date at the top of this page indicates when it was last revised.

10. Contact

For any questions regarding this Privacy Policy or the data practices of Media Agency, please contact the application owner directly.
